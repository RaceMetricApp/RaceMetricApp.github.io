RaceMetric Support

RaceMetric is a karting logbook and driver-performance app by JH43 Racing. If you need help, want to report a problem, or have a feature request, contact RaceMetric support.

  • What happened instead.
  • Screenshots if they help explain the issue.

Common Help

My data is missing

RaceMetric stores data locally on your device. Installing an update normally keeps that data, but deleting the app, wiping the device, or reinstalling can remove it. Use Setup > Export full backup before changing devices or reinstalling where possible.

Logger import does not read my file

RaceMetric supports native UniPro .uni sessions and UniPro TSV/CSV exports. Depending on the channels in the selected file, an import can include lap and sector times, GPS, speed, RPM, temperature, steering, battery and acceleration data. Logger formats and firmware exports can vary, so contact support with a sample if a valid file is not recognised.

Why is some telemetry unavailable?

RaceMetric only displays channels that are present and usable in the selected logger file. Lap times may be available even when GPS, RPM, sectors or other sensors were not recorded. The theoretical lap uses valid logger sector times when they are available.

How do session comparisons work?

Open a saved session with logger data and choose Compare with another session. RaceMetric offers compatible sessions from the same circuit, then aligns the selected laps by track position so their racing lines, sectors and available telemetry can be inspected together.

My onboard video will not open

RaceMetric copies selected onboard footage into its local app storage so it remains attached to the session. Large files need enough free device space. If the original import was interrupted or the local file is no longer available, use Replace to attach the video again.

Why does RaceMetric ask for location?

Location is optional and is used for circuit/session location features. When event weather is enabled, RaceMetric sends the selected circuit coordinates and event date to Open-Meteo for a forecast. RaceMetric does not use background location tracking.

Why does RaceMetric ask for Motion & Fitness?

Motion & Fitness is optional and is used to show daily step count on the dashboard. Steps do not affect the driver rating.

Why does RaceMetric ask for photo-library access?

Photo-library access is optional and is used when you choose a dashboard logo, driver image, coach video, session-note photo, or onboard session footage. RaceMetric only uses the item you select.

Why does RaceMetric ask for notifications?

Notifications are optional and are used for local race-weekend and planned-session reminders, plus one-time alerts when an engine reaches a rebuild target set by the driver. Event and session reminders may include the latest available daily or hourly circuit forecast when event weather is enabled.
